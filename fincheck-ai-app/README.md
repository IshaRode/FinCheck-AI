# FinCheck AI — Frontend Web Application

This directory contains the Next.js 16 web application for **FinCheck AI**.

For complete project documentation, architectural details, and product overview, please refer to the [Root README](../README.md).

## Quick Start

### 1. Install Dependencies

```bash
npm install
```

### 2. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production

```bash
npm run build
npm run start
```

### 4. Run Linter

```bash
npm run lint
```

## Tech Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript 5**
- **Tailwind CSS v4**
- **Lucide Icons**
